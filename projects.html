FirstLight Energy Network Infrastructure Update

I helped configure and upgrade a network infrastructure from an older system to newer equipment. I reviewed the existing network and looked at common failure points so the new setup could be more reliable and secure. I also worked with firewall settings and QoS to help prioritize important network traffic. This project gave me more hands-on experience with real network equipment and showed me how much planning is involved when upgrading an existing environment.

CCNA Final Networking Project

For my CCNA final project, I designed and configured a multi-city network that connected different locations using WAN technologies. I worked with routers, switches, IP addressing and routing so each location could communicate with the others. I had to troubleshoot different connection issues throughout the project and make sure the routing was working correctly. It helped me understand how larger networks are built and how multiple sites can communicate over long distances.

Legend of Zelda GUI Game Project

I programmed my own version of The Legend of Zelda with a graphical user interface and interactive gameplay. I worked on different parts of the game such as player movement, controls, objects and how the user interacted with the game. There were a lot of bugs along the way, so I spent a lot of time testing and fixing different parts of the program. This project helped me become more comfortable with programming and taught me how different parts of a larger program have to work together.

Engineering Animation Project

During my engineering studies, I created an animation as part of one of my technical projects. I used programming and design concepts to control movement and visual changes throughout the animation. I had to adjust timing and movement several times before everything worked the way I wanted it to. It was one of the projects that showed me how programming can be used for more than just calculations and can also be used to create visual and interactive work.

TacOPS Competition - OTU NetSoc

I participated in TacOPS hosted by OTU NetSoc, where my team finished in third place against many other teams. The competition involved technical challenges, coding, teamwork and an authorized security challenge involving a Verkada-based security system. Some parts of the competition were physically demanding as well, so we had to stay focused and work together under pressure. It was a great experience because it tested more than just technical knowledge and required teamwork, problem-solving, willpower and physical endurance.
