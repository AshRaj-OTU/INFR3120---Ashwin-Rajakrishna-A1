My website uses Fluid Design and Media Queries.

I used three separate CSS files.

full.css is used full screen desktops
tablet.css is used for tablet or laptop screen sizes from 481px to 960px.
phone.css is used for phone screen sizes 480px and below.
I used these sizes to create separate layouts for laptop, tablet and mobile screens.
Percentage widths are used so the page content can adjust to the screen size.
i didnt use flexbot.
gradients:
I used a normal linear gradient for the main page background, linear-gradient(to bottom), then I used an angled linear gradient for the header, linear-gradient(45deg,)
I also used a black and gold color scheme for a clean and professional appearance, a bit more astehtic

The colors I chose are

#000000 - Black
#D4AF37 - Gold
#1F1F1F - Dark Charcoal
#F5F5F5 - White
#8C6B1F - Dark Gold

i put black and dark charcoal to keep a move asethtic look, and the gold is used mainly for navigation and accents. 
White is used for text, dark gold is used in the angled gradient.
