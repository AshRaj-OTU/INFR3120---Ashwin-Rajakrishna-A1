The website uses three separate CSS files to acustom different screen asizes
full.css - 960px and above
tablet.css - 481px to 960px
phone.css - 480px and below

These sizes allow the website to adjust for desktop, tablet, and phone screens. Percentage widths are used so the content can resize itself within the browser.
Gradients:
Normal linear gradient used for the page background:
linear-gradient(to bottom, #000000 0%, #1F1F1F 100%)
Angled linear gradient used in the header:
linear-gradient(45deg, #000000 0%, #8C6B1F 100%)
Color Scheme:
The website uses a black and gold colour scheme created with Adobe Color.

#000000 - Black
#D4AF37 - Gold
#1F1F1F - Dark Charcoal
#F5F5F5 - Off White
#8C6B1F - Dark Gold

Black and dark charcoal are used for the backgrounds. Gold and dark gold are used for headings, navigation, borders, and accents. Off white is used for the main text.
